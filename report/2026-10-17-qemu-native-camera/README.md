# A7C II 原生 QEMU 相机实验

目标是运行 ILCE-7CM2 2.01 的原始相机应用，并逐步接入显示、物理控件、虚拟成像和文件保存。这是正在实现的研究成果，**目前不能称为完整相机模拟器**。

本次公开范围与验收状态见 [2026-10-17 阶段进展](STATUS.md)。公开仓库提供源码与复现工具，不附Sony原始固件、私有配置、运行日志或生成程序；这些输入/产物须按本文在本机准备。

首次使用先读 [启动前准备](PREREQUISITES.md)：官方BODYDATA/分区镜像、fastboot与SD卡路线、必需文件、下载依赖及宿主资源。

本目录是唯一交付位置。原始研究证据仍保留在工作区；后续发布用文档、源码和脚本直接在这里维护。

## 当前可核验的结果

| 能力 | 状态 | 验证方式 |
|---|---|---|
| 原固件菜单和图像资源 | 已通过 | 原应用生命周期、实际 GPE 绘图及 Sony LZ77 解码 |
| 标准 QEMU ramfb 显示 | 已通过 | 原核 fw_cfg DMA，QMP 截帧与校验后的 AP 位图逐像素一致 |
| GTK 原生窗口 | 限定九步场景通过 | 实际窗口画布与 AP 快照逐像素一致，包含拨盘，正常 Quit 返回0 |
| 上下左右、确认、MENU、删除/C2 | 基本菜单操作已通过 | 真实屏集、高亮、帮助页及像素变化；原生按钮另有隔离 GUI 测试 |
| 右后拨盘正反转 | 菜单操作已通过 | 原生按钮及 PageUp/PageDown；单次有符号增量，无伪释放 |
| 全部可点击控件布局 | 已实现 | 原生 GTK 侧栏；未核准的键和拨盘暂为灰色 |
| 播放、C1、录像、模式档位/三档开关 | 继续验证 | 已有精确静态输入契约，拍摄上下文仍未恢复；不能只根据发送成功判可用 |
| 退出菜单后的拍摄主界面 | 未恢复 | 当前会进入 shooting 后回到 boot，AP 提交空帧 |
| 虚拟 CMOS、镜头和对焦 | 调查/实现中 | 必须进入固件实际请求与消费路径 |
| 固件拍照、录像并保存电脑磁盘 | 未完成 | 不用主机生成图片或录屏冒充固件产物 |
| 原 Fsys 虚拟磁盘写入/导出 | 已通过独立验证 | 双进程重挂读回、全镜像校验、fsck和目录/内容解析 |

当前 AP 软件图形模型使用 RGBA4444/source-over/nearest，不声称与实体硬件逐像素一致。CP 图层合成、传感器和编码器属于独立的待恢复链路。

## 启动当前可运行版本

本机已装配的版本可直接运行：

```bash
./start.sh
```

需要 Linux X11/Xwayland 桌面。方向键导航、Enter 确认、M/Esc 返回、Delete 删除/帮助、F12 保存界面快照。
右侧九个可用操作正常显示，其余十四项为灰色。PageUp/PageDown 分别将右后拨盘左转/右转一步。退出最外层菜单目前会进入未恢复的拍摄初始化状态；这不是实时取景。

**日期设置确定键故障已修复**：启动器现在通过原日期服务初始化并读回时钟；用户操作及后续日期编辑页导航共123步重放通过。初始时间取原固件默认值 `2023-01-01`，不是主机时间。基础导航测试仍不覆盖所有菜单入口；详情见 [启动故障记录 §11](BOOT-TROUBLESHOOTING.md)。

首次从源码准备资产时，使用自己取得并解包的2.01固件：

```bash
./import-assets.sh --firmware-root /path/to/unpacked-firmware --fdat /path/to/firmware.fdat
```

导入器拒绝覆盖已有资产。细节见 [资产导入说明](runtime/analysis/ASSET-IMPORT.md)；源码分发不包含 Sony 库、字体和研究者设备设置。
固定资产集合、摘要与执行权限均校验；本机已通过独立目录和路径含空格的完整菜单运行测试。

## 交付原则

- 仅本机隔离 QEMU，无真实相机、物理 SD 或磁盘直通。
- 主机磁盘只用于实验文件、虚拟存储和导出的成果。
- 代码与开源依赖单独交付；Sony 固件由使用者自行提供，版本和摘要须匹配。
- 通过导入器干净生成 rootfs，使用固件包 ALLLANG 默认设置；不分享研究者的设备私有 Backup/setting。
- 原始固件不修改。IMDB 的十个实验服务掩码变更、虚拟身份卷和软件设备模型必须明确标注。
- 一键菜单启动和干净资产导入已可用；完整 QEMU 源码差分、全部控件及拍摄链仍在整合，未完成步骤不会写成已验收。
